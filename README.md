The toast class is `group toast group-[.toaster]:bg-background group-[.toaster]:text-foreground group-[.toaster]:border-border group-[.toaster]:shadow-lg`. The description class is `group-[.toast]:text-muted-foreground`. The action button is `group-[.toast]:bg-primary group-[.toast]:text-primary-foreground`. The cancel button is `group-[.toast]:bg-muted group-[.toast]:text-muted-foreground`. `QueryClient` is created and no page calls it. The only route is `/`, and every other path renders the 404 page. The search field keeps its text after a search. The form submit receives `date`, `time`, `partySize`, `location`, and `budget`, and `Index` ignores that object. The stored party sizes are `"2"`, `"3"`, `"4"`, and `"5"`. The stored budgets are `"budget"`, `"moderate"`, `"upscale"`, and `"premium"`. A booking id other than `"1"`, `"2"`, or `"3"` makes the toast title `Booking undefined...`. The three buttons pass those three ids. The commits on 2025-10-13 are from gpt-engineer-app[bot].
